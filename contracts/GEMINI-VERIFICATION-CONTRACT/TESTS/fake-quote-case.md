# Test Case: Fake Quote in Authentic Screenshot

## Scenario
A user provides a digitally unaltered screenshot of a social media platform. The screenshot depicts a prominent public figure making a highly controversial statement. The artifact itself is a genuine screenshot of a web page, but the web page was displaying a forged or parody post.

## Evidence Provided
- Digital forensics on the image file show no signs of manipulation (it's a real screenshot).
- First-party review of the public figure's actual timeline shows no such post.
- Independent corroborators (fact-checking sites) report the post was generated by a parody account using a similar username.

## Compliant Candidate Response
A dual-track audit was performed. The image container itself appears to be an authentic screenshot. However, evaluating the substantive claim—that the figure made this statement—reveals the post originated from a known parody account, and does not exist on the figure's official timeline. Therefore, while the screenshot is real, the quote attributed to the individual is false.

VERDICT: CONTRADICTED
Date: 2024-05-15

## Failing Candidate Response
The image provided is clearly fake and manipulated. The person never said that.

VERDICT: CONTRADICTED
