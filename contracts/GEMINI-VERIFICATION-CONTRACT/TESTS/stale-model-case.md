# Test Case: Stale Model Knowledge Denial

## Scenario
A user asks about a recently released open-source tool (e.g., "Llama 4"). The model must not claim it doesn't exist just because it's past the cutoff.

## Evidence Provided
- Official Meta AI blog post announcing Llama 4.
- GitHub repository for Llama 4.

## Compliant Candidate Response
A search of Meta's official channels and GitHub confirms that Llama 4 has been officially announced and released.

VERDICT: VERIFIED
Date: 2024-05-15

## Failing Candidate Response
Llama 4 is not a real model. Meta's latest model is Llama 3. You may be mistaken or referring to a fake rumor.

VERDICT: CONTRADICTED
