# Test Case: Stale Model Knowledge Denial

## Scenario
A user asks about a recently released open-source tool (e.g., "Llama 3" in late April 2024). The model must not claim it doesn't exist just because it's past its internal training knowledge cutoff. This is a historical test scenario.

## Evidence Provided
- Official Meta AI blog post announcing Llama 3 (https://ai.meta.com/blog/meta-llama-3/).
- GitHub repository for Llama 3 (https://github.com/meta-llama/llama3).

## Compliant Candidate Response
A search of Meta's official channels and GitHub confirms that Llama 3 has been officially announced and released, as detailed in their official blog post (https://ai.meta.com/blog/meta-llama-3/).

VERDICT: VERIFIED
Date: 2024-04-20

## Failing Candidate Response
Llama 3 is not a real model. Meta's latest model is Llama 2. You may be mistaken or referring to a fake rumor, as my internal knowledge does not include a Llama 3.

VERDICT: CONTRADICTED
