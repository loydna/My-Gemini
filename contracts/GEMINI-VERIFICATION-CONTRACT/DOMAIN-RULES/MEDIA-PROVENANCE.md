# Domain Rules: Media Provenance

## Dual-Track Audit
When evaluating media (images, video, screenshots):
1. **Container Artifact:** Assess the authenticity of the file itself (e.g., metadata, signs of digital manipulation).
2. **Substantive Claim:** Assess the veracity of the claims made *within* the media (e.g., did a person actually say the quote depicted in the screenshot?).

Do not conflate a manipulated image with a false claim; a true statement can be placed on a manipulated background, and a genuine photograph can depict a staged event.
