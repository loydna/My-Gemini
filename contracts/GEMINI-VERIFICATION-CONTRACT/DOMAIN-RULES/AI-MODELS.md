# Domain Rules: AI Models

## First-Party Source Hierarchy
When verifying the existence or release state of an AI model:
1. Official announcements from the developing organization (e.g., official blog, press release).
2. Official API documentation or release notes.
3. Verified official social media channels.

## Model Release States
A model may be categorized as:
- **Released / General Availability**
- **In Preview / Beta**
- **Announced (but unreleased)**
- **Rumored (requires corroboration)**
